# 🏚️ survival-city — Выживание: Бедный квартал

Браузерная 2D survival/economic RPG с видом сверху. Персонаж стартует обычным
человеком: **0 $, без жилья, работы и транспорта**. Его потребности, навыки,
одежда и социальный статус напрямую влияют на то, что доступно в городе.

## Системы персонажа

- **Потребности (0–100)**: здоровье, сытость, жажда, энергия, гигиена,
  настроение, стресс, комфорт (от погоды и одежды). Тихо тают со временем —
  без микромуджинга.
- **Характеристики**: Сила (физ. работа), Выносливость (расход энергии),
  Интеллект (скорость обучения), Харизма (торговля/продажа), Ловкость
  (скорость ходьбы/бега).
- **Навыки (0–10)**: Физический труд, Торговля, Кулинария, Вождение,
  Механика, Медицина, Общение, Компьютеры. Растут от использования;
  уровни повышают характеристики и открывают работы:
  курьер → водитель, подсобник → механик, принят → фельдшер,
  продавец-кассир, оператор на удалёнке.
- **Социум**: репутация (−100…+100), образование, профессия и стаж,
  правовой статус, документы (оформляются после 3 смен уборки; нужны
  для водителя), адрес или статус «Бездомный» (комната в ночлежке —
  первый «адрес»).
- **Экономика**: наличные, банковский счёт (банкоматы), кредит с
  ежедневными платежами и процентами, последние/суммарные доходы и траты.
- **Одежда**: слоты Голова/Верх/Низ/Обувь, тепло, качество, износ.
  Влияет на комфорт, гигиену и внешний вид персонажа на карте.
- **Состояния**: Голод, Обезвоживание, Усталость, Грязный, Замёрз,
  Простуда, Болезнь, Травма, Сыт, Бодрость, Хорошо отдохнул — каждое с
  конкретным игровым эффектом.
- **Инвентарь**: ограничен (6 мест, +6 с рюкзаком). Действия: съесть/
  выпить/применить/надеть/снять/выбросить, продажа в магазине.
- **Транспорт**: велосипед (B) — быстрее, но сушит и утомляет.
- **Автосохранение**: весь персонаж, инвентарь, одежда, работа, деньги,
  позиция и время сохраняются в localStorage; есть «Продолжить».

## Мир

Квартал 34×17: дороги, тротуары, парк с лавками, мусорные баки (шуршинг),
банкоматы и здания: магазин «Скидка» (торговля + продажа), ночлежка
«Рассвет» (улица/койка/комната), автосервис «Гараж», медпункт (работы +
душ), склад №7 (разгрузка/курьер/водитель), кафе «Гусяк», интернет-кафе
«Вайфай» (ПК + удалёнка), участок «Южный» (уборка + документы),
заброшенные дома. Погода (ясно/пасмурно/дождь), день/ночь.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Ходьба (шаг = 2 игровые минуты) |
| Shift | Бег (быстрее, тратит энергию и воду) |
| Клик мышью | Путь к тайлу / к входу в здание |
| E | Действие: двери, лавки, баки, банкоматы |
| B | Велосипед: сесть/сойти |
| C | Профиль персонажа |
| I | Рюкзак |
| Esc | Закрыть окна |

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Прод-сборка и проверка:

```bash
npm run build
npm start
npx tsx scripts/sim.ts   # автотест игровых сценариев (редьюсер)
```

## Стек и структура

Next.js (App Router) + React + TypeScript + Tailwind CSS. Карта — canvas,
интерфейс — React. Вся игровая логика отделена от компонентов:

- `src/game/world.ts` — сетка, здания, BFS-путь, взаимодействия.
- `src/game/data.ts` — предметы, работы, каталоги, константы.
- `src/game/types.ts` — типы: CharacterState, Needs, Stats, Skills,
  Equipment, ActiveStatus, Inventory, GameState, Action.
- `src/game/character.ts` — старт персонажа, тик потребностей, температура,
  навыки, правила работы и торговли.
- `src/game/reducer.ts` — единый редьюсер игровых правил.
- `src/game/save.ts` — автосейв в localStorage.
- `src/game/render.ts` — отрисовка (статичный слой + персонаж с анимациями
  idle/walk/run/work/rest, 4 направления, велосипед, ночь, дождь).
- `src/components/Game.tsx` — ввод, HUD, профиль (C), инвентарь, диалоги.
- `scripts/sim.ts` — проверка сценариев (старт → работа → документы →
  магазин → одежда → банк/кредит → сон → смерть → рестарт → сейв).
