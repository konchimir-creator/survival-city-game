# Survival City

Браузерная 2D survival/economic RPG на **Next.js 14 + TypeScript + React**.

Персонаж начинает с 0₽, без жилья, работы и транспорта, в бедном городском квартале.

## Механики MVP
- **Карта квартала** — 8 интерактивных зданий, перемещение кликом (тратит энергию и время; велосипед делает перемещение бесплатным).
- **Работы** — рынок, склад, кафе, стройка. Оплата, затраты энергии/времени, риск травмы, работа с требованием инструмента.
- **Магазин** — еда, кофе, аптечки, велосипед, ящик с инструментом.
- **Ночлежка / улица / съёмная комната** — сон восстанавливает энергию, аренда 400₽ за 7 дней.
- **Инвентарь** и использование предметов.
- **Показатели**: деньги, здоровье, энергия, голод; игровые часы и дни.
- **Автосохранение** в localStorage, журнал событий, конец игры при 0 здоровья.

## Запуск
```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production-сборка
```

## Структура
```
app/            — Next.js App Router (layout, page, styles)
app/components/ — Game.tsx — весь игровой UI
lib/game.ts     — модель данных: локации, работы, предметы, расчёты
```
