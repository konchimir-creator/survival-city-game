# 🏚️ survival-city — Выживание: Бедный квартал

Браузерная 2D survival/economic RPG с видом сверху. Персонаж стартует обычным
человеком: **0 $, без жилья, работы и транспорта**. Его потребности, навыки,
одежда и социальный статус напрямую влияют на то, что доступно в городе.

## Системы персонажа

- **Потребности (0–100)**: здоровье, сытость, жажда, энергия, гигиена,
  настроение, стресс, комфорт (от погоды и одежды). Тихо тают со временем —
  без микромуджинга.
- **Характеристики**: Сила (физ. работа), Выносливость (расход энергии),
  Интеллект (скорость обучения), Харизма (торговля/продажа), Ловкость
  (скорость ходьбы/бега).
- **Навыки (0–10)**: Физический труд, Торговля, Кулинария, Вождение,
  Механика, Медицина, Общение, Компьютеры. Растут от использования;
  уровни повышают характеристики и открывают работы:
  курьер → водитель, подсобник → механик, принят → фельдшер,
  продавец-кассир, оператор на удалёнке.
- **Социум**: репутация (−100…+100), образование, профессия и стаж,
  правовой статус, документы (оформляются после 3 смен уборки; нужны
  для водителя), адрес или статус «Бездомный» (комната в ночлежке —
  первый «адрес»).
- **Экономика**: наличные, банковский счёт (банкоматы), кредит с
  ежедневными платежами и процентами, последние/суммарные доходы и траты.
- **Одежда**: слоты Голова/Верх/Низ/Обувь, тепло, качество, износ.
  Влияет на комфорт, гигиену и внешний вид персонажа на карте.
- **Состояния**: Голод, Обезвоживание, Усталость, Грязный, Замёрз,
  Простуда, Болезнь, Травма, Сыт, Бодрость, Хорошо отдохнул — каждое с
  конкретным игровым эффектом.
- **Инвентарь**: ограничен (6 мест, +6 с рюкзаком). Действия: съесть/
  выпить/применить/надеть/снять/выбросить, продажа в магазине.
- **Транспорт**: велосипед (B) — быстрее, но сушит и утомляет.
- **Автосохранение**: весь персонаж, инвентарь, одежда, работа, деньги,
  позиция и время сохраняются в localStorage; есть «Продолжить».

## Мир

Квартал **96×48** (3072×1536 px) — старый район (34×17) сохранён без
изменений, старые сейвы остаются совместимыми. Вокруг — продлённые улицы
(горизонтальные на y=8/30, вертикальные на x=22/54/78), тротуары, три парка
и скверы, периметр с воротами, ~28 зданий: магазин «Скидка» (торговля +
продажа), ночлежка «Рассвет» (улица/койка/комната), автосервис «Гараж»,
медпункт (работы + душ), склад №7 (разгрузка/курьер/водитель), кафе
«Гусяк», интернет-кафе «Вайфай» (ПК + удалёнка), участок «Южный» (уборка +
документы), заброшенные дома, плюс новые: «Угол», «Борщ», больница, полиция,
«Склад №12», «Пит-Лайн», «Северный», «Южный» (рынок), «Огонёк», «Тёплая»,
медпункт «Южный», «Центр» и школы. Погода (ясно/пасмурно/дождь), день/ночь.

## Визуал и рендер

- **Полноэкранный canvas** на весь viewport (dpr-aware) + **плавная камера**
  со сглаживанием (tau ≈ 110 мс) и ограничением границами мира. Мышь
  переводится в тайлы через камеру (`screenToWorld`).
- **Предвычисленные текстуры** (один раз, не в цикле): грунт 2× (асфальт с
  фактурой и трещинами, бордюры, разметка, зебры, люки, лужи, парковка),
  канвас на каждое здание (крыша с кондиционерами/трубами, фасад с
  градиентом и потёками, окна/витрины/роллеты, маркизы у кафе и магазинов,
  дверь со ступенькой, вывеска) и база миникарты.
- **Depth-sort по линии опоры** (низ объекта) для зданий, декораций
  (деревья, лавки, баки, банкоматы, фонари, знаки, гидранты, столбы,
  билборды, припаркованные машины, заборы, ящики), машин, NPC и игрока.
  В кадр попадают только объекты видимой области (culling).
- **День/ночь**: темнение без «чёрной плёнки», светящиеся окна и витрины,
  свечение вывесок, мягкие пулы света от фонарей, свет в дверях ночлежек и
  медпунктов, фары машин, мигалка полиции.
- **Дождь** (существующая система погоды): капли, потемнение, мокрый
  асфальт, шиммер и рябь в лужах — сдержанно.
- **Живой город**: NPC (6 архетипов, 4 палитры из `npcs.png`, разная
  скорость, маршруты по тротуарам, паузы «постоит и пойдёт») и транспорт
  (седаны, такси, фургон, полиция) на полосах в виде замкнутых петель.

## Спрайт-листы

Функциональные спрайт-листы для карты с видом сверху. Генерируются
процедурно — детерминированно и без зависимостей:

- `public/sprites/character-sheet.png` — лист героя **1152×768**,
  **прозрачный PNG**: 4 ряда (вниз/вверх/влево/вправо) × 9 колонок
  (idle, walk 1–4, run 1–4). Кадр **128×192**, одинаковый масштаб во всех
  кадрах, тень строго внутри кадра; без текста, подписей и фона.
- `public/sprites/npcs.png` — лист NPC **1152×3072**: 16 рядов
  (4 палитры × 4 направления) × 9 колонок тех же анимаций.
- `public/sprites/character-meta.json` — метаданные (размеры, порядок).
- `tools/sprites/character-sheet-preview.png` — превью на шахматке
  (только для контроля, не ассет).

Персонаж: обычный молодой человек — потрёпанное тёмное худи с молнией,
шнурками и карманом, выцветшие джинсы с пятнами, дешёвые кроссовки, старый
рюкзак с лямками, растрёпанные волосы. Пропорции близки к человеческим
(голова ~1/5 роста), сдержанная городская палитра, вид 3/4 сверху.

Игра использует лист напрямую: `src/game/sprites.ts` загружает PNG один раз,
до загрузки рисует программный placeholder. Тело персонажа — кадры листа
(idle = кол. 0; walk циклически 1→4; run циклически 5→8, скорость кадров
зависит только от состояния и не зависит от FPS), ноги заземлены в
координате тайла (якорь внутри кадра x=64, y=172), на карте спрайт
**64×96 px** (рост ~86 px) и растёт вверх от них.
Глубина — по Y линии опоры. Коллизии не меняются (маленькие, у ног).
Велосипед и поза «лёжа» (отдых на лавке) остаются программной отрисовкой —
в листе таких кадров нет.

Повторная генерация:

```bash
node tools/sprites/render-sheet.js             # листы + метаданные
node tools/sprites/render-sheet.js --debug 7   # один кадр крупно (tools/sprites)
```

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Ходьба (шаг = 2 игровые минуты) |
| Shift | Бег (быстрее, тратит энергию и воду) |
| Клик мышью | Путь к тайлу / к входу в здание |
| E | Действие: двери, лавки, баки, банкоматы |
| B | Велосипед: сесть/сойти |
| C | Профиль персонажа |
| I | Рюкзак |
| Esc | Закрыть окна |
| Кнопки HUD | Профиль / Рюкзак / Телефон (позвонить другу, 1 раз в день) |

Интерфейс — оверлеи поверх игрового полотна: статус-пилы (❤️ 🍗  ⚡ 💵,
время) сверху слева, кнопки сверху справа, контекстная подсказка «E — …»
снизу, лог событий снизу слева, миникарта (дороги, здания, игрок, цель,
граница видимости) снизу справа.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Прод-сборка и проверка:

```bash
npm run build
npm start
npx tsx scripts/sim.ts          # автотест игровых сценариев (редьюсер)
npx tsx scripts/verify-sprite.ts # пайплайн спрайтов и depth (mock-canvas)
npx tsx scripts/smoke-frame.ts   # смоук кадра: ночь/дождь/края/NPC/машины
```

## Стек и структура

Next.js (App Router) + React + TypeScript + Tailwind CSS. Карта — canvas,
интерфейс — React. Вся игровая логика отделена от компонентов:

- `src/game/world.ts` — сетка 96×48, здания, декор/зебры/люки/лужи,
  BFS-путь, взаимодействия.
- `src/game/data.ts` — предметы, работы, каталоги, константы.
- `src/game/types.ts` — типы: CharacterState, Needs, Stats, Skills,
  Equipment, ActiveStatus, Inventory, GameState, Action.
- `src/game/character.ts` — старт персонажа, тик потребностей, температура,
  навыки, правила работы и торговли.
- `src/game/reducer.ts` — единый редьюсер игровых правил.
- `src/game/save.ts` — автосейв в localStorage.
- `src/game/camera.ts` — камера: плавное следование, границы мира,
  world↔screen, видимая область.
- `src/game/sprites.ts` — загрузка листов (один раз) + математика кадров.
- `src/game/entities.ts` — NPC (маршруты, скорость, паузы) и транспорт
  (полосы, петли) — чистая симуляция.
- `src/game/render.ts` — текстуры (грунт/здания/миникарта), кадр с
  камерой и culling'ом, depth-sort, персонаж из character-sheet.png
  (idle/walk/run, 4 направления, анимация по времени), NPC из npcs.png,
  транспорт, ночь с живым светом, дождь; велосипед/отдых — программно.
- `src/components/Game.tsx` — полноэкранный canvas, ввод (клавиатура/мышь
  через камеру), HUD-оверлеи (статус, кнопки, подсказка, лог, миникарта,
  тач-дпад), профиль (C), инвентарь, диалоги.
- `scripts/sim.ts` — проверка сценариев (старт → работа → документы →
  магазин → одежда → банк/кредит → сон → смерть → рестарт → сейв).
- `scripts/verify-sprite.ts` — проверка пайплайна рендера: кадры
  спрайт-листа, якорь у ног, depth-проход (mock-canvas, без браузера).
- `tools/sprites/render-sheet.js` — процедурный генератор спрайт-листа
  персонажа (чистый Node, без зависимостей; см. «Спрайт-лист персонажа»).
