# 🏚️ survival-city — Выживание: Бедный квартал

Браузерная 2D survival/economic RPG. Персонаж стартует с **0 $**, без жилья, работы и
транспорта — и попадает в бедный городской квартал, где можно выжить, если не стоять
на месте.

## MVP (первая играбельная версия)

- **Квартал**: тайловая карта 30×17 — дороги с разметкой, тротуары, парк, забор по
  периметру и два заброшенных дома для атмосферы.
- **Интерактивные здания**: магазин «Скидка», ночлежка «Рассвет», Склад №7,
  кафе «Гусяк», участок «Южный».
- **Работы**: три подёнщины (разгрузчик, кухня, уборка улиц) — платят деньги,
  отнимают энергию и время, работают только в часы смены.
- **Магазин**: хлеб, вода, сэндвич, газировка, энергетик. Открыт 08:00–21:00.
- **Ночлежка**: платная койка (полное восстановление энергии) или бесплатная,
  но плохая ночь на улице.
- **Инвентарь**: еда и напитки берутся из рюкзака (клавиша I).
- **Энергия и голод**: тают со временем; при полном голоде энергия падает быстро,
  при 0 сил на исходе — смерть и экран «начать заново».
- **День/ночь**: квартал темнеет, загораются окна, вокруг персонажа — слабый свет.
- **Шерстинг и отдых**: мусорные баки (шанс найти еду или монетки), лавки в парке
  (бесплатное восстановление энергии).
- **Журнал событий** и экраны интро/смерти.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Прод-сборка:

```bash
npm run build
npm start
```

## Управление

| Клавиша            | Действие                                   |
| ------------------ | ------------------------------------------ |
| WASD / стрелки     | Ходьба (шаг = 2 игровые минуты)            |
| Клик мышью         | Путь к тайлу / к входу в здание            |
| E                  | Действие с ближайшей дверью/лавкой/баком   |
| I                  | Рюкзак                                     |
| Esc                | Закрыть окна                               |

## Стек и структура

Next.js (App Router) + React + TypeScript + Tailwind CSS. Карта рисуется на canvas,
интерфейс — React.

- `src/game/world.ts` — сетка, здания, BFS-путь, взаимодействия.
- `src/game/data.ts` — каталоги предметов и работ, цены.
- `src/game/reducer.ts` — игровое состояние и правила (работа, покупки, сон, смерть).
- `src/game/render.ts` — отрисовка (статичный слой квартала + динамическая рамка).
- `src/components/Game.tsx` — компонент игры: ввод, HUD, диалоги, оверлеи.

## Дорожная карта

- Транспорт (автобус/велосипед) и новые районы города.
- Жильё: аренда комнаты, покупка дома.
- Сохранение прогресса (localStorage) и профиль персонажа.
- Рынок сменных работ, погода, случайные события.
- Мобильное управление (заготовка D-pad уже есть).
